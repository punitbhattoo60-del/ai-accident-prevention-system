# AI-Based Accident Prevention System

**"See the Danger Before You Can See It."**

A premium project website for an AI-based accident prevention system that uses roadside cameras, YOLO object detection and OpenCV to spot hidden hazards — blind spots, hidden pedestrians and sudden obstacles — calculate collision risk, and warn drivers early.

## Tech shown on the site
- Python, YOLO, OpenCV, Machine Learning
- React / JavaScript
- ESP32 (planned hardware integration)

## Note
The Live AI Dashboard on the site uses clearly labelled simulated demo data until real AI camera integration is available.
